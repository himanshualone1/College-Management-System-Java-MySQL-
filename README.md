🎓 College Management System (Java + MySQL)
📘 Overview

College Management System (Java + MySQL) is a desktop-based application built using Java Swing and MySQL Database.
It allows colleges to manage student records efficiently — including adding, viewing, updating, and deleting student information.

⚙️ Features

➕ Add new student details

✏️ Update existing records

❌ Delete student entries

🔍 Retrieve student data from MySQL

💾 Secure database integration with JDBC

🖥️ User-friendly Java Swing interface

🛠️ Tech Stack

Language: Java

UI Framework: Swing

Database: MySQL

JDBC Driver: MySQL Connector/J

IDE: IntelliJ IDEA / NetBeans
